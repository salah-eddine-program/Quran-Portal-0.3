## 🌙 نبذة عن المشروع | About the Project

**Quran Portal 0.3** هي منصة ويب عربية متجاوبة تهدف إلى تقديم تجربة قرآنية وإسلامية متكاملة، من خلال جمع مجموعة من الأدوات والخدمات في واجهة واحدة سهلة الاستخدام.

توفر المنصة إمكانية قراءة القرآن الكريم والاستماع إلى التلاوات، والبحث في الآيات وتحليل كلماتها، والاطلاع على التفسير والترجمات، وتنظيم الحفظ والمراجعة، ومتابعة الأذكار اليومية، بالإضافة إلى مواقيت الصلاة واتجاه القبلة والتقويم.

يعتمد المشروع على **Next.js 15 App Router وTypeScript**، مع تصدير ثابت لملفات HTML بهدف النشر على GitHub Pages.

## ✨ الأقسام والميزات الرئيسية

### 📖 1. المصحف الشريف
- فهرس السور والأجزاء.
- الانتقال المباشر إلى أي آية.
- حفظ موضع القراءة الأخير.
- التحكم في حجم الخط وإعدادات القراءة.
- حفظ السور المقروءة محلياً للقراءة دون اتصال.
- إضافة السور والآيات إلى المفضلة.
- نسخ الآيات وإنشاء بطاقات صور للمشاركة.

### 🎧 2. التلاوات القرآنية
- تشغيل تلاوة الآيات من قراء مختلفين.
- دليل للقراء والتلاوات من MP3Quran.
- تشغيل السور والإذاعات القرآنية.
- تصفية القراء حسب الرواية المسجلة في المصدر.
- تكرار الآية أو نطاق من الآيات.
- التحكم في سرعة التشغيل والانتقال التلقائي.

### 🔍 3. البحث والتفسير والتحليل
- بحث عربي مطبّع في الأقسام والسور والآيات.
- الانتقال المباشر باستخدام صيغة `رقم السورة:رقم الآية`.
- الوصول إلى التفسير العربي المتاح.
- ترجمات معاني القرآن:
  - الإنجليزية.
  - الفرنسية.
  - الإسبانية.
  - الأردية.
- تحليل كلمات الآيات نحوياً وصرفياً عبر Quranic Arabic Corpus.

### 📝 4. الحفظ والمراجعة
- خطة مراجعة يومية وأسبوعية.
- جدولة متباعدة لمراجعة الآيات.
- تقييم مستوى المراجعة.
- اختبارات ذاتية للآيات المحفوظة.
- شارات الإنجاز ومتابعة التقدم.
- حفظ بيانات خطة المراجعة محلياً.

### 🤲 5. الأذكار اليومية
- مجموعة من الأذكار اليومية.
- إمكانية البحث عن الأذكار.
- عداد لتكرار الذكر.
- تشغيل الصوت عند توفره.
- حفظ بيانات الأذكار والعدادات محلياً بعد تحميلها.

### 🕌 6. الخدمات الإسلامية
- مواقيت الصلاة.
- التقويم الهجري والميلادي.
- حساب اتجاه القبلة حسب المدينة المختارة.
- عداد التسبيح.
- روابط إلى حصن المسلم ومصادره.

### ⚙️ 7. التخصيص وتجربة المستخدم
- الوضع الليلي والنهاري.
- إعدادات القراءة والصوت.
- واجهة مبسطة اختيارية.
- تخصيص ألوان وحجم خط بطاقات المشاركة.
- دعم تثبيت الموقع كتطبيق PWA.
- تصدير واستيراد النسخ الاحتياطية.

## 🔐 البيانات والخصوصية

- لا يتطلب الموقع إنشاء حساب أو تسجيل الدخول.
- تحفظ المفضلة وآخر قراءة والملاحظات والإعدادات محلياً على الجهاز.
- تُخزّن السور التي تمت قراءتها باستخدام IndexedDB.
- لا يطلب التطبيق إذن تحديد الموقع الجغرافي.
- ترسل عبارة البحث في الآيات إلى Al Quran Cloud عند استخدام البحث.
- ترسل المدينة وطريقة حساب المواقيت إلى AlAdhan عند طلب مواقيت الصلاة.
- يفتح تحليل الكلمات في Quranic Arabic Corpus عبر صفحة خارجية.
- تُحمّل بيانات الأذكار عند الطلب من مصدرها الخارجي.
- لا تحفظ ملفات الصوت الخارجية تلقائياً دون اتصال.
- لا تتضمن النسخة الاحتياطية ملفات الصوت أو بيانات IndexedDB.
- لا تتوفر مزامنة سحابية أو حسابات مستخدمين أو لوحة إدارة للمحتوى في نسخة GitHub Pages.

**ملاحظات مهمة:**
- قد تختلف مواقيت الصلاة المحسوبة عن مواقيت المسجد المحلي.
- طريقة الحساب الافتراضية هي طريقة الجزائر `19`، ويمكن اختيار طرق أخرى.
- تعرض قائمة القراء الروايات وفق البيانات المسجلة في MP3Quran فقط.
- تغيير القارئ لا يغيّر رسم المصحف، ولا يتوفر خيار نصي لورش دون مصدر نصي موثوق ومعتمد.
- تُنسب بيانات الأذكار إلى مصادرها، مع مراعاة التحقق من النصوص والأعداد.

## 🚀 التشغيل المحلي | Local Development

### المتطلبات

- Node.js 20.9 أو أحدث.
- npm.
- Git.

### خطوات التشغيل

**1. استنساخ المستودع:**

```bash
git clone https://github.com/salah-eddine-program/Quran-Portal-0.3.git
```

**2. الدخول إلى مجلد المشروع:**

```bash
cd Quran-Portal-0.3
```

**3. تثبيت الحزم:**

```bash
npm ci
```

**4. تشغيل بيئة التطوير:**

```bash
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

### فحص المشروع وبناؤه

```bash
npm run lint
npm run typecheck
npm run build
npm run check:export
```

تُحفظ ملفات النشر الثابتة في:

```text
out/
```

## 🌐 النشر على GitHub Pages

يستخدم المشروع GitHub Actions لأتمتة عملية البناء والنشر.

ملف سير العمل:

```text
.github/workflows/pages.yml
```

لتفعيل النشر:

1. افتح مستودع المشروع على GitHub.
2. انتقل إلى **Settings**.
3. اختر **Pages**.
4. من **Build and deployment** اختر **GitHub Actions**.

يقوم سير العمل ببناء التطبيق ورفع محتويات `out/`، مع ضبط `basePath` تلقائياً لمستودعات GitHub Pages.
